Po kilku latach blog działał na generatorze statycznym Scully opartym o Angulara. Postanowiłem przenieść go na Roq – generator statyczny stron zbudowany na Quarkusie. Dzięki temu cały blog jest teraz budowany przez Javę, a treść mogę pisać w AsciiDoc.

== Co się zmieniło

Największą zmianą jest silnik: zamiast Node.js i Angulara używam Quarkusa oraz wtyczek Roq. Z tego wynikają nowe możliwości:

* treść w AsciiDoc (postach) oraz Markdown (podstrony),
* tagi i kategorie,
* wyszukiwarka (lunr),
* generowanie kart Open Graph,
* diagramy z kodu dzięki Kroki,
* kolorowanie składni dzięki highlight.js.

== Admonitions

Roq i Asciidoctor wspierają wyróżnione bloki informacyjne. Oto wszystkie dostępne warianty:

NOTE: Zwykła notatka z dodatkową informacją.

TIP: Wskazówka, która może się przydać.

IMPORTANT: Ważna informacja, o której warto pamiętać.

WARNING: Ostrzeżenie o możliwych problemach.

CAUTION: Przestroga – warto zachować ostrożność.

== Kolorowanie składni

Bloki kodu są kolorowane automatycznie. Oto kilka przykładów.

[source,bash]
----
roq generate
roq start
----

[source,properties]
----
site.url=https://miroslaw.ovh
quarkus.asciidoc.attributes.icons=font
----

[source,java]
----
public class Hello {
    public static void main(String[] args) {
        System.out.println("Witaj, Roq!");
    }
}
----
